# StudySpot

## Comandi per avviare il progetto

### Avvio del server
Per avviare il server, eseguire il seguente comando nella directory `server`:
```bash
npm run server
```
Questo comando avvia il server Node.js.

### Apertura del client nel browser
Per aprire il client nel browser, eseguire il seguente comando nella directory `server`:
```bash
npm run client
```
Questo comando apre automaticamente il browser all'indirizzo `http://localhost:3004`.

## Note aggiuntive
- Assicurarsi che tutte le dipendenze siano installate eseguendo `npm install` nella directory `server` prima di avviare il progetto.
- Utilizzare `Ctrl+C` per fermare il server quando è in esecuzione.
